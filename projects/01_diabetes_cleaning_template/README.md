## Overview

This project focuses on clinical data quality assessment, cleaning, validation, and exploratory analysis using the Diabetes 130-US Hospitals dataset.

The objective is to simulate a clinical data management workflow, including data review, identification of inconsistencies, missing data evaluation, and preparation of a clean analytical dataset.
