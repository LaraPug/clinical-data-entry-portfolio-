# Clinical Data Entry Portfolio

## Overview

This repository demonstrates practical skills in Clinical Data Entry, Data Cleaning, Quality Control, and Data Validation using Excel and R.

## Objectives

- Simulate a clinical data management workflow.
- Perform data quality checks.
- Clean and validate clinical datasets.
- Document all procedures following Good Clinical Practice (GCP) principles.

## Tools

- Microsoft Excel
- R
- RStudio
- Git
- GitHub
- Visual Studio Code

## Project Structure

- data/: Raw and cleaned datasets
- documentation/: SOPs, query logs, data dictionary
- excel/: Validation rules and templates
- R/: Data processing scripts
- reports/: Validation reports
- images/: Figures and workflow diagrams
