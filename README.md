# Clinical Data Entry Portfolio

## Overview

This repository demonstrates practical skills in Clinical Data Entry, Data Cleaning, Quality Control, and Data Validation using Excel and R.

## Objectives

- Simulate a clinical data management workflow.
- Perform data quality checks.
- Clean and validate clinical datasets.
- Document all procedures following Good Clinical Practice (GCP) principles.

## Tools

- R
- RStudio
- Git
- GitHub
- Visual Studio Code

- data/: Raw and cleaned datasets

- reports/: Validation reports

# Clinical Data Entry & Clinical Research Portfolio

## Overview

This repository contains a collection of clinical data management and data analysis projects developed to demonstrate skills in clinical data entry, data quality control, cleaning, validation, and statistical analysis.

The projects are based on publicly available clinical datasets and follow principles aligned with Good Clinical Practice (GCP), reproducible research, and scientific documentation standards.
